

## 0. Project Name

**CrypNote** – Web platform for learning cryptography for CTF.



## 1. Problem

Crypto learning is messy. Resources are scattered, too advanced, and lack direction. Beginners waste time, get confused, and avoid crypto challenges.



## 2. Users

**Primary:** New CTF players

- Some coding knowledge
    
- Weak in math/crypto
    
- Want practical understanding
    

**Secondary:** Cybersecurity students

- Limited time
    
- Need fast clarity
    



## 3. Pain Points

1. No roadmap
    
2. Hard explanations
    
3. Little guided practice
    
4. Forgetting topics
    
5. Tools without understanding
    



## 4. Goal

Provide a clear step-by-step path from basics → solving crypto problems.



## 5. Requirements

- Runs in browser
    
- Beginner-friendly
    
- Lessons + quizzes
    
- Quick references
    
- Track progress
    



## 6. Success Metrics

- High module completion
    
- Better quiz scores over time
    
- More users willing to attempt crypto in CTFs
    


## 7. MVP

**Include:**

- Structured modules
    
- Short lessons
    
- Auto-checked quizzes
    
- Reference pages
    
- Progress view
    

**Exclude (for now):**

- Gamification
    
- Real CTF competitions
    
- Social features
    



## 8. User Flow

Open site → start module → learn → take quiz → get feedback → continue.



## 9. Design Priorities

- Always show the next step
    
- Keep screens simple
    
- Focus on learning, not decoration
    



## 10. Testing

Give beginners tasks.  
Watch where they struggle, hesitate, or quit.  
Improve those areas.
